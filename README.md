# nickolasdeluca/homebrew-tap

Homebrew casks for my apps.

```sh
brew install --cask nickolasdeluca/tap/<cask>
```

| Cask | App |
|------|-----|
| `buildkite-notch` | [Buildkite Notch](https://github.com/nickolasdeluca/buildkite-notch): macOS notch that tracks Buildkite builds and deploys |

Casks are updated automatically by each app's release script.
